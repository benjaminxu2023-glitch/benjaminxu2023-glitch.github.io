QuaStat

轻量的质量统计分析工作台。单个 HTML 文件，中英文界面可切换。

在线打开

数据只在本地浏览器中处理，不会上传。推荐使用 Chrome 或 Edge。

功能

  • 描述性统计
  • 正态性检验（Anderson–Darling）
  • 过程能力：Cp/Cpk、Pp/Ppk、Cpm，可按 Cavity 分组比较
  • Xbar-R / I-MR 控制图
  • Gage R&R
  • t 检验、单因素 ANOVA、线性回归
  • 主效应分析、DOE 设计生成器
  • 常用图形和 Graph Builder

无需安装或构建，在浏览器中打开即可使用。

数值验证

计算结果与多个独立来源逐项比对，作为持续集成的硬门禁：任何一项超出容差，测试即失败。

  • 独立实现：Python（numpy / scipy / statsmodels）与 R（base R、nortest）
  • NIST StRD 认证数据集：单变量统计 9 个、单因素 ANOVA 11 个、线性回归 Norris
  • NIST/SEMATECH e-Handbook 例题（过程能力、t 检验数据、控制图系数）
  • Monte Carlo（已知真值，检验 d2、c4 等常数）

当前版本在持续集成中 1006 项检查全部通过。主要约定：过程能力默认用单值 MR(2) 估算组内σ；空白单元格按缺失处理（不当 0）；Cpm 按 Minitab 的定义计算。

尚未有公开认证数据对照的部分：Gage R&R、Welch t 检验（只与 Python、R 独立实现比对），主效应与 DOE 设计（只与 Python 比对）；回归只支持一元线性。

这是软件数值验证，不等同于医疗器械质量体系下的正式软件确认（validation）。用于正式记录前，请按贵司程序自行确认。
