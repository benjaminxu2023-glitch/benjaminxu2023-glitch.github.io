QuaStat

轻量的质量统计分析工作台，单个 HTML 文件，中英文界面可切换。当前版本 V5.9.0。

在线打开（需兑换码）

数据只在本地浏览器中处理，不会上传。无需安装或构建，推荐使用 Chrome 或 Edge。

功能

工作表与数据工具

  • 导入 xlsx / csv / txt / tsv，或直接粘贴表格
  • 堆叠列、拆分列、排序、计算器，撤销上一步
  • 空白单元格按缺失处理（不当 0）；按项目隔离的设置记忆，切换数据集不会串参数

基础统计

  • 描述性统计
  • 正态性检验（Anderson–Darling，输出 A²、A²* 与 P 值）
  • 容差区间

过程能力

  • Cp / Cpk、Pp / Ppk、Cpm，支持单侧公差
  • 组内 σ 可选单值 MR(2)、按子组列、指定子组大小，或直接用整体标准差
  • 按 Cavity（或任意列）分组比较各腔能力，并按腔出 Capability Sixpack 六图
  • 非正态与变换：Box-Cox、Johnson 变换、Weibull、Lognormal

控制图

  • 计量型：Xbar-R、Xbar-S、I-MR、I-MR-R/S
  • 计数型：P / NP / C / U，样本量不等时用逐点控制限
  • 判异规则支持 Minitab Test 1–8（均值图）；R/S/MR 与计数型图按惯例用 Test 1–4。可按 Cavity 分组，各腔独立定限

测量系统分析

  • Gage R&R（交叉 ANOVA，含交互项，α=0.25 取舍规则；%Contribution、%StudyVar、%Tolerance、ndc）
  • 计数型一致性分析（Attribute Agreement，κ）

假设检验

  • 单样本 t、双样本 t（Welch）、配对 t
  • 双方差：Bonett、Levene、F 检验
  • 单比率、双比率、卡方关联
  • 等效性检验 TOST

质量工程与设计

  • 单因素 ANOVA（含 Tukey 多重比较）
  • 一元线性回归
  • 主效应分析
  • DOE 设计生成器：2k 全因子、部分因子、响应曲面 CCD，可设重复与区组
  • DOE 因子分析

图形与 Graph Builder

  • 直方图、箱线图、点图、单值图、区间图、散点图、时间序列图、多变异图、概率图、Pareto 图
  • 每张图都可在 Graph Builder 里选列、选分组后重绘，并导出高清 PNG

PCS 过程能力研究报告

医疗器械包装常用的过程能力研究报告（PCS），从数据到可签核的文档一条链路：

  • 导入 PCS 版式的 Excel，自动识别项目信息与各尺寸规格；识别不了的字段会明确列出并留空，不猜
  • Cpk 总结图、原始数据页、每腔一页 Capability Sixpack、正态性检验页
  • 导出 A4 横向报告，打印或另存为 PDF；也可导出数据到 Excel

数值验证

统计结果与多个互相独立的来源逐项比对，作为持续集成的硬门禁：任何一项超出容差，测试即失败。

  • 独立实现：Python（numpy / scipy / statsmodels）与 R（base R、nortest）
  • NIST StRD 认证数据集：单变量统计 9 个、单因素 ANOVA 11 个、线性回归 Norris
  • NIST/SEMATECH e-Handbook 例题（过程能力、t 检验数据、控制图系数）
  • Monte Carlo（固定种子，用已知真值检验 d2、c4 等常数）
  • Minitab 官方 Methods and formulas（按其公式独立实现并比对）
  • 一份本地 Minitab 报告逐项对照（数据不入库，持续集成中跳过）

合计 1066 项核对全部通过（含本地 Minitab 对照 60 项；持续集成环境中无该报告，跑 1006 项，同样全部通过）。另有 140 项旧版核验与 33 项界面/回归测试一并通过。

方法与公式按 Minitab 官方文档实现，数值经上述多源交叉验证；这不等于逐图逐版面与 Minitab 输出核对过。界面版式与图形形态仍以本工具自身设计为准。

主要约定：过程能力默认用单值 MR(2) 估算组内σ；空白单元格按缺失处理；Cpm 按 Minitab 的定义计算。

尚未有公开认证数据对照的部分：Gage R&R、Welch t 检验（只与 Python、R 独立实现比对），主效应与 DOE 设计（只与 Python 比对）；回归只支持一元线性。非正态能力（Weibull / Lognormal / Johnson）只给整体 Pp/Ppk 与预期 PPM。

这是软件数值验证，不等同于医疗器械质量体系下的正式软件确认（validation）。用于正式记录前，请按贵司程序自行确认。
